# US-058 - Tenant admin manages custom roles & permissions

## Story

As a tenant admin, I want to create custom roles, toggle permissions for manager/employee/custom roles, assign roles to staff, and always retain full tenant access myself, so access control matches how my team actually works without ever locking myself out.

## Acceptance criteria

- [x] Create a custom role via permission toggle switches grouped by resource. (FR-16.2, FR-16.5)
- [x] Edit manager/employee/custom role permission sets; changes take effect and invalidate the permission cache. (FR-16.4, FR-16.5)
- [x] Tenant admin retains full tenant access regardless of toggle state; admin role shown as "Full tenant access" with always-on/disabled toggles, not deletable/renamable. (FR-16.3)
- [x] Delete an unused custom role; deleting an assigned role returns 409. (FR-16.5)
- [x] Assign a custom role to staff via the Team page role select (last-admin guard preserved). (FR-16.5, FR-16.6)
- [x] Backend + frontend enforcement: has_permission bypass for super_admin/tenant-admin, DB grants for others; UI gated via can(action, resource). (FR-16.4, FR-16.6)
- [x] Role create/edit/delete/assign and reset-defaults actions audited. (FR-16.5)
- [x] Reset defaults restores system role permission sets. (FR-16.5)
