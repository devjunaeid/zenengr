# US-041 — Email notification on new comment respecting visibility

## Story

As a project participant, I want to receive an email notification when a new shared comment is posted so I can stay informed without actively checking the platform.

## Acceptance criteria

1. Email notification is sent to relevant participants when a new shared comment is posted. (FR-10.5, AC-6)
2. Email notification is NOT sent for internal-only comments. (AC-7)
3. Notification includes: project name, comment author, snippet of content. (FR-10.5)
4. Notification respects user's notification preferences (opt-out possible). (FR-11.3)
5. Client users receive notifications only for shared comments on their own projects. (FR-10.5)
