# US-039 — Tenant and Client users post/view project comment thread

## Story

As a tenant staff member or client user, I want to post and view messages on a project thread so I can communicate with the project team.

## Acceptance criteria

1. Each Project has a comment/activity thread. (FR-10.1, AC-1)
2. Tenant Admin/Manager/Employee can post a comment on a project thread. (AC-1)
3. Client User can post a comment on a project thread visible to them. (FR-10.1, AC-2)
4. Comments record author, author type (tenant/client), timestamp, and content. (FR-10.2, AC-5)
5. Thread is accessible from both Admin Portal and Client Portal (scoped appropriately). (AC-8)
6. MVP scope: Project-level threads (not milestone-level). (FR-10.4)
