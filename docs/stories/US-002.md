# US-002 — Backend Docker image

## Story

As a developer, I want a Dockerfile for the FastAPI backend so I can run the API in the local Compose stack and connect it to Postgres and Redis.

## Acceptance criteria

1. `backend/Dockerfile` builds an image based on Python 3.14.
2. Image installs dependencies via `uv sync` (or `pip install` from `pyproject.toml`).
3. Image starts the API with `uvicorn` (FastAPI `[standard]` entrypoint) bound to `0.0.0.0:8000`.
4. Container exposes port `8000`.
5. A `.dockerignore` excludes `.venv`, `__pycache__`, `.pytest_cache`, etc.
6. Env vars `DATABASE_URL` and `REDIS_URL` are read by the app and wired through the Compose service.
