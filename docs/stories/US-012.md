# US-012 — Tenant Admin invites a staff user with pre-assigned role and expiring invite

## Story

As a Tenant Admin, I want to invite a new admin user via email with a pre-assigned role so I can onboard my team securely without sharing passwords.

## Acceptance criteria

1. Tenant Admin can invite a new admin user by email with role pre-assignment (Admin, Manager, Employee). (FR-4.1, FR-4.9)
2. Invite link expires after a defined period (e.g., 7 days). (FR-4.9)
3. Expired invite cannot be used to register. (FR-4.9)
4. Invited user receives an email with a registration link. (FR-4.9)
5. After registration, the user can log into the Admin/Ops Portal with assigned role permissions. (AC-2, FR-4.3)
6. Invite flow is tracked in the audit trail. (FR-4.13)
