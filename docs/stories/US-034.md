# US-034 — Client User views own invoices with status and balance due

## Story

As a Client User, I want to view my invoices with current status and balance due so I can track what I owe.

## Acceptance criteria

1. Client Portal shows all invoices for the client's projects. (FR-8.6, AC-6)
2. Each invoice displays: number, issue date, due date, amount, status, balance due. (FR-8.6)
3. Invoice detail view shows line items and payment history. (FR-8.6)
4. Client User can download PDF of their invoices. (FR-8.7)
5. Client User cannot edit or void invoices (view-only). (FR-8.6)
6. Invoices from other clients in the same tenant are NOT visible. (FR-4.8)
