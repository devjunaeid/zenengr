# US-020 — Client activity timeline auto-logs relationship events

## Story

As a staff member, I want to see an automatic activity timeline per client so I can track all interactions and events related to that client without manual logging.

## Acceptance criteria

1. System auto-logs events per Client: project created, invoice issued, payment received, comment posted. (FR-5.6, AC-4)
2. Activity timeline is displayed on the Client detail page. (FR-5.6)
3. Events are ordered by timestamp (newest first). (FR-5.6)
4. Each event shows: event type, timestamp, and brief description. (FR-5.6)
