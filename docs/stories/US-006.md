# US-006 — Tenant Admin edits own tenant profile and branding

## Story

As a Tenant Admin, I want to view and edit my own tenant's profile (business name, logo, contact info, branding) so I can present a professional appearance to my clients without involving the Super Admin.

## Acceptance criteria

1. Tenant Admin can view their own tenant's profile information. (FR-1.5)
2. Tenant Admin can edit business name, logo, contact info, and branding fields. (FR-1.5)
3. Tenant Admin CANNOT change subscription tier, feature flags, or platform-level settings. (FR-1.5)
4. Changes take effect immediately on next page load. (FR-1.5)
5. Super Admin can also edit these fields from the Super Admin panel. (FR-1.1)
6. Edits are logged in the audit trail. (FR-4.13)
