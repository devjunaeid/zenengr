# US-056 - General (internal) invoices without project or client

## Story

As a tenant admin, I want to create general invoices that belong to neither a project nor a client (tenant-internal billing: internal works/misc charges), so my staff can bill tenant-internal items without linking them to external entities.

## Acceptance criteria

- [x] Create general invoice with custom line items only (no project/client linkage). (FR-15.1)
- [x] Issue with same gapless numbering sequence as project invoices. (FR-15.1)
- [x] Void behaves like project invoices. (FR-15.1)
- [x] Staff-only visibility: never in client portal, never in client financial rollups. (FR-15.1, FR-15.7)
- [x] Draft/issue/void lifecycle matches project invoices. (FR-15.1)
