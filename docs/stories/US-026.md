# US-026 — Staff update project milestone status, dates, assignee (4-status enum)

## Story

As a staff member, I want to update milestone status (Pending, In Progress, Completed, Blocked), planned dates, and assignee so I can track project progress.

## Acceptance criteria

1. Staff can update a milestone's status to any of the 4 values: Pending, In Progress, Completed, Blocked. (FR-6.4, AC-7)
2. Status can be changed in any order (non-sequential completion allowed). (AC-7)
3. Staff can set/update planned/target date and actual completion date. (FR-6.4)
4. Staff can assign an admin user to a milestone. (FR-6.4)
5. Employee can only update milestones on assigned projects. (FR-4.2, FR-6.6)
6. Milestone status changes are visible (read-only) on Client Portal. (FR-6.6, AC-8)
