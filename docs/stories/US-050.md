# US-050 — Visibility scoping: user-isolated vs tenant-level

## Story

As a tenant staff member, I want user-isolated and tenant-level files with enforced permissions so private files stay private and team files are shared with the right people.

## Acceptance criteria

- [x] USER files only visible to uploader (list + download + delete). (FR-12.5)
- [x] TENANT files visible to all staff. (FR-12.5)
- [x] Delete/rename restricted to admin/manager for TENANT, creator for USER. (FR-12.5)
- [x] Upload allowed for all staff. (FR-12.3)
- [x] Server-side enforcement with 404 on unauthorized access (never 403 detail leak). (FR-12.5)
