# US-051 — Protected project files with client access

## Story

As a tenant staff member or client user, I want project files protected with scoped access so only the right tenant staff and the owning client can view/download them, and confidential files are never on public URLs.

## Acceptance criteria

- [x] PROJECT files require `project_id`. (FR-12.3)
- [x] All tenant staff can view/download. (FR-12.5)
- [x] Upload by admin/manager only. (FR-12.5)
- [x] Client users of the project's client can view/download their project files in the client portal. (FR-12.5)
- [x] Any other client gets 404. (FR-12.5)
- [x] Downloads of PROJECT files audited. (FR-12.6)
- [x] Content never on a public URL. (FR-12.6)
