# US-010 — Super Admin manages per-tenant feature flags with plan defaults and per-tenant override

## Story

As a Super Admin, I want to enable/disable feature flags per tenant and set plan-level defaults so I can control feature rollout at the tenant level without code changes.

## Acceptance criteria

1. Super Admin can view a list of all feature flags for a tenant with current on/off state. (AC-1)
2. Super Admin can toggle a flag on/off per tenant. (FR-3.1, AC-2)
3. Feature flags are data-driven (key-value/boolean registry per tenant). (FR-3.2)
4. Flags have default values per Plan; Super Admin can override per tenant. (FR-3.3, AC-5)
5. Super Admin override persists independently of Plan defaults. (AC-6)
6. Adding a new flag key to the database makes it available immediately without code deploy. (AC-7, FR-3.5)
