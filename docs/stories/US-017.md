# US-017 — Audit trail records sensitive admin actions

## Story

As the system, I want to record sensitive admin actions (role changes, deactivations, invoice issuance, payment recording) so that tenant admins can review who did what and when.

## Acceptance criteria

1. System records audit log entries for: role changes, user deactivations/reactivations, invoice issuance, payment recording. (FR-4.13)
2. Each entry includes: who performed the action, what action, timestamp, and relevant entity ID. (FR-4.13)
3. Audit log is viewable by Tenant Admin. (FR-4.13)
4. Audit entries are append-only — no editing or deletion. (FR-4.13)
5. A simple activity log list is sufficient for MVP. (FR-4.13)
