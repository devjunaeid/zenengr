# US-009 — Tenant Admin edits permitted tenant settings; SA-only settings enforced per permission table

## Story

As a Tenant Admin, I want to edit settings that are flagged as tenant-editable (default currency, invoice numbering format, timezone, date format) so I can tailor the platform to my business, while Super Admin retains control of platform-level settings (email sender identity).

## Acceptance criteria

1. Tenant settings include: default currency, invoice numbering format, timezone, date format, email sender identity. (FR-2.4)
2. A permission table defines per-setting: `Super Admin only`, `Tenant Admin editable`, or `Tenant Admin viewable only`. (FR-2.5)
3. Tenant Admin can edit settings flagged as "Tenant Admin editable". (AC-4)
4. Tenant Admin can view but NOT edit settings flagged as "Super Admin only". (AC-5)
5. Invoice numbering format setting controls the generated invoice number pattern (e.g., INV-2026-0001) and is tenant-scoped gapless sequential. (AC-7, FR-2.5)
