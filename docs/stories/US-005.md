# US-005 — Super Admin manages tenant lifecycle (edit, suspend, cancel)

## Story

As a Super Admin, I want to view, edit, suspend, and deactivate tenants so I can manage tenant lifecycle from trial through active to offboarding.

## Acceptance criteria

1. Super Admin can view a list of all tenants with status, plan, and key metadata. (FR-1.1)
2. Super Admin can edit a tenant's profile fields (name, contact info) after creation. (FR-1.1)
3. Super Admin can suspend a tenant; suspended tenants' users lose portal access. (FR-1.3)
4. Super Admin can deactivate/delete a tenant; deactivated tenant data is preserved but inaccessible. (FR-1.3)
5. Status transitions are logged in the audit trail. (FR-4.13)
6. Suspended tenant users receive appropriate error on login attempt. (FR-1.3, AC-4)
7. Tenant Admin cannot change tenant's subscription tier or platform-level feature flags. (FR-1.5)
