# US-025 — Staff create a Project bundling services; milestones instantiate per FR-6.4

## Story

As a Tenant Admin or Manager, I want to create a project for a client by selecting one or more services so the milestone template is automatically instantiated as project milestones.

## Acceptance criteria

1. Tenant Admin/Manager can create a Project with name, client, start date, status, and owner. (FR-7.1, FR-7.2, AC-1)
2. One or more Services from the catalog can be selected at project creation. (FR-7.1)
3. Each selected service instantiates its milestone template into concrete Project Milestones. (FR-6.4, FR-7.3, AC-2)
4. Instantiated milestones have status Pending and planned dates derived from the template. (FR-6.4, AC-4)
5. Project status defaults to Draft on creation. (FR-7.2)
