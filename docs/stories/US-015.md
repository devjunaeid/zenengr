# US-015 — RBAC permission matrix enforced server-side for Admin/Manager/Employee

## Story

As the authorization system, I want to enforce the FR-4.2 permission matrix at every API endpoint so users can only perform actions their role allows.

## Acceptance criteria

1. Admin role has full access to all tenant capabilities per FR-4.2 matrix. (AC-3)
2. Manager can manage clients, services, projects (assigned), invoices, payments, but NOT admin users or tenant settings. (FR-4.2, AC-6)
3. Employee sees only assigned projects; can update milestone status on assigned projects; CANNOT create invoices or record payments. (FR-4.2, AC-7)
4. All three roles can edit own profile/password. (FR-4.2)
5. Permission check is enforced server-side — UI hiding is secondary. (FR-4.2)
6. Role changes take effect on next request. (FR-4.10)
7. Every protected endpoint checks the caller's role against the permission matrix. (AC-3, AC-6, AC-7)
