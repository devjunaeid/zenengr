# US-060 - Client portal notifications synced with admin

## Story

As a client user, I want to receive realtime in-app notifications for activity on my own client's projects and invoices so I stay informed without being able to see anything from other clients.

## Acceptance criteria

- [ ] Client user receives an in-app notification for their own client's projects/invoices on: invoice issued, payment received, milestone completed, shared comment. (FR-17.3, AC-4)
- [ ] Never receives notifications for other clients' data; cross-tenant impossible. (FR-17.3, AC-8)
- [ ] Realtime delivery in the client portal via WebSocket push + unread badge. (FR-17.4, AC-5)
- [ ] Read state separate per user (mark read / mark all in client portal). (FR-17.5, AC-1)
- [ ] Client notification links to the entity page. (FR-17.7, AC-7)
