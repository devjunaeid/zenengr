# US-069 - Tenant Numbering System Setting & Dynamic Amount in Words on Inputs

## User Story

As a **tenant administrator**,
I want to **configure our regional numbering system (International Millions/Billions vs South Asian Lakh/Crore) and have amount inputs dynamically show the amount spelled out in words below input labels**,
so that **users can verify large transaction sums accurately without miscounting zeros**.

## Acceptance Criteria

1. Backend accepts `number_system` tenant setting with `international` (default) and `south_asian` (and `indian` alias).
2. The `Settings -> Configuration` UI includes a "Numbering System" selector under Regional / Financial settings with a live example preview.
3. The frontend reactive store `tenantSettings` provides `number_system`.
4. A dedicated utility `numberToWords(amount, system)` accurately converts numeric inputs to English words in both International and South Asian systems:
   - International: 1,500,000 -> "One million five hundred thousand"
   - South Asian: 1,500,000 -> "Fifteen lakh", 15,000,000 -> "One crore fifty lakh"
   - Handles decimal values cleanly (e.g. "and 50/100" or "point five zero").
5. Amount inputs (invoice unit prices, payment dialog amounts, refund amounts, advance amounts, service rates) display a small dynamic in-words line directly underneath their labels as users type.
6. When input is 0 or blank, no text clutter is shown.
