# US-023 — Staff manage Service catalog with ordered milestone template steps

## Story

As a Tenant Admin or Manager, I want to create and manage a catalog of services, each with an ordered milestone step template, so I can standardize project delivery.

## Acceptance criteria

1. Tenant Admin/Manager can create a Service with name, description, default price, and ordered milestone steps. (FR-6.1, AC-1)
2. Each milestone step has a name, sequence order, optional expected duration, and description. (FR-6.2, AC-2)
3. Different services can have different milestone counts and structures. (FR-6.3, AC-3)
4. Services can be edited after creation. (FR-6.1)
5. Employee role has view-only access to the service catalog. (FR-4.2)
