# US-043 — User changes own password; forgot-password email flow

## Story

As any logged-in user, I want to change my password (with current-password confirmation) or reset it via email if forgotten so I can maintain account security.

## Acceptance criteria

1. Any logged-in user can change their own password with current-password confirmation. (FR-11.2, AC-3)
2. Incorrect current password rejects the change. (AC-3)
3. Forgot-password flow sends a reset link to the user's email. (FR-11.2, AC-4)
4. Reset link expires after a defined period. (FR-11.2)
5. Password change is logged in the user's activity history. (FR-11.5, AC-10)
6. Password changes follow the tenant's password policy (minimum length, etc.). (FR-11.2)
