# US-055 - Tenant-wide currency/date/timezone formatting

## Story

As a tenant admin, I want to set my tenant's currency, timezone, date format, and time format once, and have them applied everywhere across both the staff and client portals, so all dates and prices render consistently for my tenant.

## Acceptance criteria

- [x] Changing currency/date/timezone/time-format reflects everywhere in both portals after reload. (FR-14.1, FR-14.3)
- [x] Date format dropdown shows live demo labels (e.g. "YYYY-MM-DD - 2026-08-05"). (FR-14.4)
- [x] Invalid currency/timezone/date_format/time_format values rejected with 422. (FR-14.5, FR-14.6)
- [x] Invoice PDF shows tenant currency symbol (map + code fallback). (FR-14.7)
- [x] Formatting helpers efficient: Intl formatters cached, rebuilt only on settings change. (FR-14.2)
