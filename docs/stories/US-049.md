# US-049 — Tenant file gallery with folder tree

## Story

As a tenant staff member, I want a file gallery with a nested folder tree so I can organize and find files by project or topic.

## Acceptance criteria

- [x] Staff can upload files (multipart). (FR-12.3)
- [x] Nested folders with create/rename/delete (empty-only delete). (FR-12.4)
- [x] Auto roots "My files"/"Team files"/"Project files". (FR-12.4)
- [x] List files per folder with pagination + metadata (name, size, type, scope, uploader, created). (FR-12.3)
- [x] Rename/move files. (FR-12.4)
