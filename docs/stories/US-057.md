# US-057 - Advance payments + ledger transactions (debit/credit, refunds)

## Story

As a tenant admin, I want overpayments to become client advances that I can manually apply to invoices, transactions to be debit/credit ledger entries including refunds, and both staff and clients to see a ledger with a running balance, so money movement is transparent and excess payments are never lost.

## Acceptance criteria

- [x] Overpay splits into applied portion + advance. (FR-15.3)
- [x] Manual apply-advance per invoice moves credit and updates status (partially_paid/paid). (FR-15.4)
- [x] Refund recorded as a credit entry (reversing applied payment or reducing advance) and audited. (FR-15.2)
- [x] Transaction amounts immutable after recording. (FR-15.2)
- [x] Ledger views (staff client detail + client portal) show Dr/Cr entries with running balance. (FR-15.5, FR-15.6)
- [x] Advance balance = advances - applied - refunded, computed live, shown staff + client portal. (FR-15.5)
