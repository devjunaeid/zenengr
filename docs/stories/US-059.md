# US-059 - Staff receive realtime permission-scoped notifications

## Story

As a staff member, I want to receive an in-app notification in realtime for each business event I have permission to see so I can react without polling the app, and so I am never shown events for modules I cannot access.

## Acceptance criteria

- [x] Receive an in-app notification on each business event the user has effective permission to see (new comment, invoice issued, payment received, refund recorded, advance applied, milestone completed, project created). (FR-17.1, FR-17.3)
- [x] No notification for events on modules without permission; super_admin/tenant-admin bypass sees all. (FR-17.3, AC-3)
- [x] Unread badge updates in realtime via WebSocket push. (FR-17.4, AC-5)
- [x] Mark a notification read; mark all read; read state persists per user. (FR-17.5, AC-1)
- [x] Notification links to the entity page (project/invoice/comment). (FR-17.7, AC-7)
- [x] In-app preference toggles per event type, default enabled; disabling stops in-app delivery for that event only (email toggle independent). (FR-17.6, AC-6)
- [x] WS reconnects automatically after disconnect. (FR-17.4, AC-5)
