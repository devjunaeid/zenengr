# US-003 — Compose stack with all services

## Story

As a developer, I want a single `docker-compose.yml` that brings up frontend, backend, Postgres, Redis, and pgAdmin together so I can start work with one command.

## Acceptance criteria

1. `docker-compose.yml` (repo root) defines services: `frontend`, `backend`, `postgres`, `redis`, `pgadmin`.
2. `postgres` image pinned (e.g., `postgres:16`); credentials from `.env`.
3. `redis` image pinned (e.g., `redis:7-alpine`).
4. `pgadmin` image configured with default login email/password from `.env`; able to connect to `postgres` service.
5. `backend` depends on `postgres` and `redis` (healthchecks).
6. `frontend` depends on `backend` (optional).
7. Named volumes for `postgres` data and `pgadmin` config (persist across rebuilds).
8. Compose loads variables from `.env`; a committed `.env.example` documents required vars.
9. `docker compose up` reaches healthy state for all services.
