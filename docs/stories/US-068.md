# US-068 - Main Invoice Table Due Date Column & Overdue Highlighting

## User Story

As a **finance officer or project manager**,
I want to **view the invoice due date directly on the main invoice list table and cards**,
so that **I can quickly identify upcoming payment deadlines and overdue invoices at a glance**.

## Context & Problem

The project invoice tab (`/app/projects/[id]`), client invoice tab (`/app/clients/[id]/invoices`), and client portal invoice list (`/client/invoices`) all display the Due Date column. However, the primary staff invoices table at `/app/invoices` only lists Total, Issued date, and Created date. Users cannot easily see when an invoice is due without opening its details.

## Acceptance Criteria

1. On the desktop table (`/app/invoices`), a `Due Date` column appears between `Total` and `Issued` (or alongside date columns).
2. If `due_date` is present, it is formatted using the tenant's configured `date_format`. If null, it displays `—`.
3. If an invoice is unpaid (`draft`, `issued`, or `partially_paid`) and `due_date` is earlier than today, an overdue visual cue (e.g. amber/red badge or indicator) is presented.
4. On mobile screen sizes (< lg), the invoice card displays `Due: <date>` alongside `Issued: <date>`.
