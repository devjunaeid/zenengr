# US-077 - Bill each charge once and keep company reports exact

## Story

As a company admin,
I want "Generate invoice" to bill only what has not been billed yet and reports to count every amount once,
So that invoice totals and company KPIs match reality.

## Acceptance Criteria

- **AC-077.1:** Generate invoice includes only charges without a non-void invoice reference; with nothing new it shows "Nothing new to bill".
- **AC-077.2:** Generate invoice auto-allocates unallocated payments (oldest first) instead of copying transactions.
- **AC-077.3:** Issuing a custom project invoice creates explicit ledger charges; voiding it creates reversals and frees the charges.
- **AC-077.4:** Report "Collected" = sum of active payments (receipts - refunds) in range, including payments with no invoice.
- **AC-077.5:** Report totals for a filter equal the sum of the matching project summaries (regression test).
- **AC-077.6:** Migration report lists projects with overlapping legacy statement invoices so the admin can void superseded ones.
