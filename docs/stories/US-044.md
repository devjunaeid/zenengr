# US-044 — User manages own notification preferences (defaults on)

## Story

As any logged-in user, I want to configure which events trigger email notifications so I can control my inbox.

## Acceptance criteria

1. Notification preferences page shows toggles for each event type: new comment, invoice issued, payment received, milestone completed. (FR-11.3, AC-5)
2. All notification types default to enabled. (FR-11.3, AC-5)
3. Disabling an event type stops email notifications for that event. (AC-6)
4. Preferences are saved per user. (FR-11.3)
5. Preferences are accessible from both Admin Portal and Client Portal. (FR-11.3)
