# US-042 — User edits own profile (both portals, per-portal field sets)

## Story

As any logged-in user, I want to view and edit my own profile (name, avatar, email, phone, timezone, language) from my portal so I can keep my information current.

## Acceptance criteria

1. Any logged-in user can view and edit their own profile fields. (FR-11.1, AC-1)
2. Profile fields: name, avatar URL, email, phone, timezone, language preference. (FR-11.1)
3. Admin Portal user sees Admin-style profile UI. (FR-11.4, AC-7)
4. Client Portal user sees Client-style profile UI. (FR-11.4, AC-7)
5. Changing email triggers re-verification flow; old email remains active until new one is verified. (FR-11.5, AC-2)
6. User cannot change role or client association via profile edit. (FR-11.6, AC-8, AC-9)
