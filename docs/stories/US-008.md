# US-008 — Super Admin manages a tenant's subscription (status, cycle, renewal)

## Story

As a Super Admin, I want to view and edit a tenant's subscription status, billing cycle, and renewal date so I can manually track subscription lifecycle.

## Acceptance criteria

1. Super Admin can assign a Plan to a tenant at creation or later. (FR-2.1)
2. Super Admin can view a tenant's current subscription status (active, past due, cancelled), billing cycle, and renewal date. (FR-2.3)
3. Super Admin can edit subscription status, billing cycle, and renewal date manually. (FR-2.3)
4. Changes are recorded in the audit trail. (FR-4.13)
5. Tenant Admin can view their own subscription plan and limits but cannot change them. (AC-3)
