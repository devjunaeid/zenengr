# US-067 — Financial Corrections for Services, Adjustments, and Payments

As a Tenant Admin or Manager,
I want to easily fix mistakes when recording service prices, ledger adjustments, or payments,
So that project statements, ledger timelines, and invoice drafts remain accurate without messy manual workarounds.

## Acceptance Criteria

1. **Service Price Edit**:
   - Given an active project service with an attached price,
   - When an admin edits the service price via the UI or API,
   - Then `price_at_attachment` is updated, the associated ledger charge entry is updated to the new price, and draft invoices containing this service sync to the new unit price.
2. **Service Removal in UI**:
   - Given an attached project service,
   - When an admin clicks "Remove Service" and confirms,
   - Then the service is unattached or soft-cancelled with a ledger reversal, and removed from the active services view.
3. **Adjustment Correction & Deletion**:
   - Given an unbilled manual adjustment entry on the project ledger,
   - When an admin edits the adjustment (amount, description, date) or deletes it,
   - Then the entry is updated or removed from the ledger timeline, and the ledger balance summary recalculates immediately.
4. **Direct Project Payment Correction & Deletion**:
   - Given a direct payment recorded on a project,
   - When an admin edits or deletes the payment,
   - Then the paid amount and balance due on the project ledger and statement are recalculated immediately.
5. **Invoice Payment Transaction Deletion**:
   - Given a payment transaction recorded on an invoice,
   - When an admin deletes the transaction from the invoice page,
   - Then the transaction is deleted, unapplied advance overages are cleaned up, and the invoice status updates based on remaining paid balance.
6. **Issued Invoice Lock Guards**:
   - Given a service charge or adjustment already referenced by an issued invoice (`invoice_ref` set),
   - When an admin attempts to edit or delete the item,
   - Then the action is rejected with a clear error indicating the covering invoice number.
