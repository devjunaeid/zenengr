# US-033 — Invoice rendered/exported as PDF

## Story

As a staff member, I want to export an invoice as a PDF so I can send it to my client or archive it.

## Acceptance criteria

1. Invoice can be exported as PDF with correct layout and data. (FR-8.7, AC-7)
2. PDF includes: invoice number, issue date, due date, line items, subtotal, tax, total, company info. (FR-8.2)
3. PDF is available for both Draft and Issued invoices (Draft optionally watermarked). (FR-8.7)
4. PDF generation is server-side and returns a downloadable file. (FR-8.7)
5. Client Portal also has PDF download for the client's invoices. (FR-8.6)
