# US-029 — Project overview shows aggregate progress + financial summary, scoped per portal

## Story

As a staff member or client user, I want to see a project overview with aggregate milestone progress and financial summary so I can track delivery and billing at a glance.

## Acceptance criteria

1. Project overview shows aggregate milestone completion percentage. (FR-7.5, AC-3)
2. Financial summary shows total invoiced, total paid, and balance due derived from linked invoices. (FR-7.5, AC-4)
3. Project overview is shown in Admin Portal (full detail). (FR-7.5)
4. Client Portal shows project overview scoped to that client's view (same project, same data but client-appropriate presentation). (FR-7.5, AC-8)
5. Linked invoices are listed in the project overview. (FR-7.5)
