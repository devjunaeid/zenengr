# US-063 — Project statement live preview, running balance & advance calculation

## Story

As a tenant admin or staff user, I want to see a live chronological financial summary of all project charges and payments with real-time due and advance balance calculations, and preview/print the statement PDF at any time without issuing an invoice.

## Acceptance criteria

- [ ] Project financial summary aggregates services (charges) and payments/advances chronologically with dates. (FR-19.1)
- [ ] Due amount is computed as $\max(\text{Total Charges} - \text{Total Paid}, 0)$ and Advance balance is computed as $\max(\text{Total Paid} - \text{Total Charges}, 0)$. (FR-19.2)
- [ ] Tenant Admin can click "Preview Statement" on the Project details page to view/print the live statement PDF anytime. (FR-19.3)
