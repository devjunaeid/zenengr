# US-032 — Staff void an issued invoice / corrections only via new documents

## Story

As a staff member, I want to void an issued invoice when it contains errors so I can prevent incorrect billing, and issue a new corrected invoice instead.

## Acceptance criteria

1. Tenant Admin/Manager can void/cancel an Issued invoice. (FR-8.3, FR-8.4)
2. Voided invoice retains its number and all original data (not deleted). (FR-8.4)
3. Voided invoice shows clearly visible status: Void/Cancelled. (FR-8.3)
4. Corrections to a voided or erroneous invoice are done via a new invoice/credit note, never by editing the original. (FR-8.4)
5. Void action is recorded in the audit trail. (FR-4.13)
