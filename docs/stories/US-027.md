# US-027 — Staff add a Service to an active Project (mid-project scope growth)

## Story

As a Tenant Admin or Manager, I want to add a new service to an existing active project so I can handle mid-project scope growth.

## Acceptance criteria

1. Tenant Admin/Manager can add a Service to an active Project after creation. (FR-7.4, AC-5)
2. Milestones instantiate for the newly added service only. (FR-7.4, AC-5)
3. The new service's milestones start at Pending status. (FR-6.4)
4. Existing milestones and services remain unchanged. (FR-7.4)
5. New service is billed via a new invoice (never reopening issued invoices). (FR-7.6, FR-8.4)
