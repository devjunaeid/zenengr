# US-030 — Staff create a Draft invoice from project services and custom line items

## Story

As a Tenant Admin or Manager, I want to create a Draft invoice for a project by selecting project services and adding custom line items so I can bill my client.

## Acceptance criteria

1. Tenant Admin/Manager can create a Draft invoice for a Project. (FR-8.1, AC-1)
2. Invoice line items are selected from existing Project Services or added as custom line items. (FR-8.1, AC-1)
3. Draft invoice captures: invoice number (assigned on issue), issue date, due date, line items, subtotal, optional tax, total, status. (FR-8.2)
4. Draft invoices are fully editable (line items, amounts, dates). (FR-8.4, AC-2)
5. A Project can have multiple invoices over its lifetime. (FR-8.5)
