# US-066 — Invoice Type Selector, Billed-To Information & Advanced Directory Filtering

## Story

As a tenant admin or manager,
I want to choose explicitly between creating a General Invoice and a Project Invoice,
and when creating a General Invoice, I want to add Billed-To information (with optional quick-fill from clients),
and when creating a Project Invoice, I want to search and select the project smoothly,
and in the invoice list, I want to filter by invoice type (General, Project, All) and optional date range,
so that I can manage both internal/ad-hoc billing and project-specific invoicing accurately and efficiently.

## Acceptance criteria

- [x] New invoice create view has a type selector between General Invoice and Project Invoice. (FR-21.1)
- [x] General invoice create form allows entering Billed-To info (Name, Email, Phone, Address, Tax ID) with optional client auto-fill. (FR-21.2)
- [x] Project invoice create form provides a real-time searchable project combobox. (FR-21.3)
- [x] `billed_to` is persisted in the database (`invoices.billed_to` JSONB) and returned via API. (FR-21.4)
- [x] Invoice detail view, edit view, and PDF render `billed_to` info for general invoices. (FR-21.5)
- [x] Invoices list page and API support filtering by type (All, Project, General) and date range (`date_from`, `date_to`). (FR-21.6)
