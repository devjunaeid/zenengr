# US-045 — User views own account security/activity history

## Story

As any logged-in user, I want to see my account activity history (email changes, password changes) so I can monitor account changes.

## Acceptance criteria

1. User's activity history shows: email changes, password changes with timestamps. (FR-11.5, AC-10)
2. Activity history is viewable from the user's profile/settings page. (FR-11.5)
3. Entries are read-only (log only, no deletion). (FR-11.5)
4. Each entry shows: event type, timestamp, and (for email changes) old and new email. (FR-11.5)
5. Activity is per-user, not admin-wide — user sees only their own history. (FR-11.5)
