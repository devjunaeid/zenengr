# US-007 — Super Admin manages subscription plans and data-driven limits

## Story

As a Super Admin, I want to create and edit subscription plans with configurable resource limits so I can adjust plan tiers without code changes.

## Acceptance criteria

1. Super Admin can create, edit, and delete subscription Plans. (FR-2.1, AC-1)
2. Each Plan defines default limits: max admin users, max clients, max active projects, max storage. (FR-2.2)
3. Limits are data-driven — editing a limit does not require redeployment. (FR-2.2)
4. When a tenant exceeds a limit, the system blocks further creation and returns an error. (AC-6)
5. Tenant Admin can view their own plan and limits but cannot change them. (AC-3)
6. Plan list shows all defined plans with their limit values. (AC-1)
