# US-046 — Backend application skeleton and tooling

## Story

As a developer, I want a bootable FastAPI backend skeleton with linting, type checking, testing, and migration tooling all passing green so I can start implementing features without setup friction.

## Acceptance criteria

1. Mandated directory layout exists per backend-standard.md.
2. `ruff check .` and `ruff format --check .` pass with configured rules.
3. `mypy app` passes with strict mode.
4. `pytest -q` passes (at least health endpoint test).
5. `alembic heads` shows clean base revision.
6. `create_app()` boots without error.
7. App exposes `GET /api/v1/health` -> `{"status": "ok"}`.
8. Config loads from environment per docker-compose env contract (database_url, redis_url, jwt_secret, environment, cors_origins).
9. Error envelope is uniform: `{"error": {"code": "...", "message": "...", "details": {...}}}`.
10. Docker entrypoints updated to `app.main:app`.
