# US-022 — Client User edits limited fields of own Client profile; billing fields staff-only

## Story

As a Client User, I want to update my own client's contact details from the Client Portal so I can keep my information current, while billing-sensitive fields remain staff-only.

## Acceptance criteria

1. Client User can view and update limited fields on their own Client profile (contact details: phone, email). (FR-5.9, AC-8)
2. Billing-sensitive fields (tax ID, billing address) are NOT editable by Client User. (FR-5.9, AC-8)
3. Tenant Admin/Manager can edit all Client fields including billing-sensitive ones. (FR-5.1)
4. Client User cannot change their role or client association via profile edits. (FR-11.6)
