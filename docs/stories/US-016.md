# US-016 — Tenant Admin/Manager invites and deactivates a Client User

## Story

As a Tenant Admin or Manager, I want to invite a Client User (client's employee) to the Client Portal so they can view their projects and invoices, and deactivate their access when needed.

## Acceptance criteria

1. Tenant Admin/Manager can invite a Client User via email for a specific Client. (FR-4.7, AC-8)
2. Invited Client User registers and logs into the separate Client Portal. (FR-4.6, AC-8)
3. Client User sees only their own Client's projects, invoices, transactions, and comments. (FR-4.6, FR-4.8)
4. Tenant Admin/Manager can deactivate a Client User's portal access. (FR-4.7)
5. Deactivated Client User cannot log into Client Portal. (AC-9)
6. Client User cannot see other clients' data, other tenants, or internal-only comments. (FR-4.8, AC-9)
