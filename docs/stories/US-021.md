# US-021 — Staff archive a Client (history preserved, portal access revoked)

## Story

As a staff member, I want to archive a client so I can clean up my active list while preserving historical projects and invoices.

## Acceptance criteria

1. Tenant Admin/Manager can archive a Client (set status to Archived). (FR-5.8, AC-6)
2. Archived Client is hidden from default active client lists. (FR-5.8, AC-6)
3. All historical projects, invoices, and payments remain intact and accessible. (FR-5.8, AC-6)
4. Archived Client's users lose Client Portal access. (FR-5.8, AC-7)
5. Archived Client can be unarchived (set back to Active). (FR-5.8)
