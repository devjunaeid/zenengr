# US-072 - Global Ledger & Company Analytics Backend Aggregations API

## User Story

As a **tenant administrator or manager**,
I want **a single, high-performance aggregation API that returns tenant-wide KPI summaries, monthly/daily timelines, and project/client breakdowns for any date window**,
so that **the frontend can render complete organization analytics in a single network round-trip without downloading and computing raw records on the client**.

## Acceptance Criteria

1. **Endpoint `GET /api/v1/tenant/reports/company-ledger`:**
   - Requires authentication and `view/financial_reports` permission.
   - Accepts optional query parameters: `date_from: date | None`, `date_to: date | None`, `client_id: UUID | None`, `project_id: UUID | None`, `granularity: str = "month"`.
2. **Executive Summary Metrics Payload:**
   - `period`: `date_from`, `date_to`.
   - `new_projects_count`: Number of projects created in the window.
   - `new_clients_count`: Number of clients onboarded in the window.
   - `new_services_count`: Number of project services attached in the window.
   - `new_services_value`: Total billable monetary value of services attached in the window.
   - `total_invoiced`: Sum of invoice totals issued in the window.
   - `total_collected`: Net payments received (debits minus refunds) in the window.
   - `total_due`: Total outstanding due across projects as of the end of the window.
   - `total_advance_balance`: Total unused advance credit balances held by clients.
3. **Timeline Trend (Month / Date-wise):**
   - Chronological buckets with `period_label` (e.g. "2026-09" or "2026-09-26"), `new_projects`, `new_clients`, `new_services`, `invoiced_amount`, `collected_amount`, `net_due_change`.
4. **Project-wise Breakdown List:**
   - Projects active or created in window, each with `project_id`, `project_short_id`, `project_name`, `client_id`, `client_name`, `status`, `services_count`, `total_value`, `total_invoiced`, `total_paid`, `balance_due`.
5. **Client-wise Breakdown List:**
   - Clients with `client_id`, `client_name`, `client_type`, `active_projects_count`, `services_count`, `total_invoiced`, `total_paid`, `total_due`, `advance_balance`.
6. Queries execute in < 250ms using indexed columns (`tenant_id`, `created_at`, `issue_date`, `recorded_at`).
