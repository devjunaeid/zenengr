# US-062 - Formal invoice generator + tagging

## Story

As a staff user, I want to generate a formal invoice from a project (or fully custom line items) and have covered charges tagged on the ledger timeline so clients and staff both see what has already been invoiced.

## Acceptance criteria

- [x] Generate an invoice from a project (project pre-selected) or from fully custom line items. (FR-18.7)
- [x] Service picker flags already-invoiced services. (FR-18.7)
- [x] Generating for a discounted project adds the discount as a negative line item so the document matches the Summary. (FR-18.7)
- [x] Draft first, then issue (existing invoice flow). (FR-18.7)
- [x] On issue, covered ProjectService charge LedgerEntries get the invoice_ref tag → "Included in INV-…" badge on the timeline. (FR-18.8)
- [x] Client portal lists issued invoices + shows the read-only timeline. (FR-18.9)
- [x] No multi-project invoices. (Out of scope)

## Notes / edge cases

- Single-project scope OR fully custom line items; NO multi-project.

- Badge text: "Included in INV-…" on the ledger timeline.
