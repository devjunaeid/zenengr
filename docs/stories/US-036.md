# US-036 — Payment allocation across line items: proportional/FIFO auto-default with manual override

## Story

As a staff member, I want to allocate a payment across specific line items so I can track how much has been paid toward each service.

## Acceptance criteria

1. Where an invoice has multiple line items, the system supports allocating a payment across specific line items. (FR-9.3)
2. System proposes proportional auto-allocation by default. (FR-9.3, AC-4)
3. Tenant staff can manually override the allocation per line item. (FR-9.3, AC-4)
4. Allocation determines how much has been paid toward each service line item. (FR-9.3)
5. Changes to allocation update line-item-level paid amounts without changing invoice total paid. (FR-9.3)
