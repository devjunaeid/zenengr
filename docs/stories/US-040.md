# US-040 — Internal-only vs shared comment visibility enforced both portals

## Story

As a tenant staff member, I want to mark comments as internal-only so sensitive discussions stay invisible to the client portal.

## Acceptance criteria

1. Tenant staff can mark a comment as "internal-only" when posting. (FR-10.3, AC-3)
2. Internal-only comments do NOT appear in Client Portal. (FR-10.3, AC-3)
3. Client User cannot see internal-only comments in any view. (FR-10.3, AC-4)
4. Shared comments are visible on both Admin Portal and Client Portal. (FR-10.3)
5. Internal-only comments are visually distinguished in the Admin Portal (e.g., badge/icon). (FR-10.3)
