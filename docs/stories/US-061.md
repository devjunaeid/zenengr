# US-061 - Project ledger: charges, payments, discount, summary

## Story

As a staff user, I want a balance-forward ledger per project (charges, derived payments, discount, live summary) so I know at a glance what is owed and why, without leaving the project.

## Acceptance criteria

- [x] Attaching a service to a project creates a charge entry (amount = price at attachment, entry_date = today). (FR-18.5)
- [x] Cancelling/removing a service writes an offsetting adjustment entry. (FR-18.5)
- [x] Payments/refunds appear on the timeline via the Transaction stream (incl. advances via allocations); nothing is mirrored into the ledger. (FR-18.2)
- [x] Discount: single active (percentage|fixed), replace-on-change, audited old/new, no reason note, never on client timeline. (FR-18.3)
- [x] Summary math live: percentage discount rounds to 2dp; fixed discount caps at Subtotal; Due = max(Total − Paid, 0). (FR-18.4)
- [x] Timeline is read-only in both portals; client portal sees charges + payments + Summary, no editing. (FR-18.9)
- [x] Manual adjustment endpoint: admin/manager only, audited, creates a manual_adjustment entry. (FR-18.6)

## Notes / edge cases

- LedgerEntry is append-only/immutable; payment stream is derived from Transactions (single source of truth).
- Discount is never shown on the client timeline; audit trail via existing audit log.
- Fixed discount min(v, Subtotal); percentage round(Subtotal × v / 100, 2).
