# US-037 — Project and Client financial rollups computed from invoices and transactions

## Story

As a staff member, I want financial rollups (Total Invoiced, Total Paid, Total Outstanding) computed from live invoice and transaction data so I can see up-to-date financial health at project and client levels.

## Acceptance criteria

1. Project financial summary shows: Total Invoiced (sum of all invoice totals), Total Paid (sum of all payments), Total Outstanding (balance due). (FR-9.4, AC-5)
2. Client-level rollups aggregate across all the client's projects. (FR-9.4)
3. Rollups are computed from live data — updating a payment immediately changes project totals. (AC-8)
4. Rollups optionally show per-service breakdown. (FR-9.4)
5. Financial rollups are accessible in both Admin Portal and Client Portal (scoped). (FR-9.5)
