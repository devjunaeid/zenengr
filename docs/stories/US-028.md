# US-028 — Cancel (not delete) an invoiced Project Service to preserve financial history

## Story

As a staff member, I want to remove a service from a project without deleting financial history so I can handle scope changes while preserving invoice integrity.

## Acceptance criteria

1. Removing a Service that has invoices referencing it marks it as Cancelled (soft removal), not deleted. (FR-7.6, AC-6)
2. Removing a Service with no invoices deletes it and its milestones entirely. (AC-7)
3. Cancelled services are clearly marked in the project overview. (FR-7.6)
4. Cancelled services' milestones retain their status and history. (FR-7.6)
5. Financial records referencing the cancelled service remain intact and unchanged. (FR-7.6)
