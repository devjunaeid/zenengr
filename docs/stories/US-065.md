# US-065 — Installable Web App Shell & PWA Support

## Story

As a staff member or client portal user, I want to install ZenEngr directly from my browser as a standalone web application on my computer or mobile home screen, with official ZenEngr branding icons and fast startup, so that I can access my workspace like a native desktop or mobile application.

## Acceptance criteria

- [x] Web App Manifest (`manifest.webmanifest`) is served with correct name, standalone display mode, brand colors, and icons. (FR-20.1)
- [x] Icon assets (512x512, 192x192, 32x32, and SVG) from `docs/dev/icons/` are placed in `frontend/static/` and referenced in HTML head and manifest. (FR-20.2, FR-20.4)
- [x] Service worker caches the client app shell assets (HTML, CSS, JS, icons) using SvelteKit `$service-worker`. (FR-20.3)
- [x] Service worker safely passes through API (`/api/v1/*`) and WebSocket (`/ws/*`) traffic without caching stale dynamic responses. (FR-20.3)
- [x] Browsers show native "Install App" triggers; optional in-app install action is available. (FR-20.5)
- [x] In-app network awareness displays a clear notification banner when the device is offline. (FR-20.6)
