# US-031 — Staff edit Draft then Issue invoice: tenant-scoped sequential number assigned, invoice locks

## Story

As a staff member, I want to edit a Draft invoice and then Issue it, which assigns a tenant-scoped sequential number and locks all financial fields so the record becomes immutable.

## Acceptance criteria

1. Draft invoice fields (line items, amounts, dates) are editable. (FR-8.4, AC-2)
2. Issuing an invoice assigns a tenant-scoped gapless sequential number following the tenant's configured format. (FR-8.2, AC-8)
3. Issuing locks all core financial fields; no further edits allowed. (FR-8.4, AC-3)
4. Issued invoice cannot be deleted; can only be Void/Cancelled. (AC-4)
5. Issued invoice status transitions to Issued/Sent. (FR-8.3)
6. Once Issued, corrections require a new document (credit note or new invoice). (FR-8.4)
7. Invoice numbering respects the tenant's configured format template (FR-2.4, AC-7).
