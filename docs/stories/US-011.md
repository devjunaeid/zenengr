# US-011 — Application enforces feature flags at runtime

## Story

As the application, I want to check feature flags before rendering UI and allowing API access so that disabled features are hidden and rejected by the server for that tenant.

## Acceptance criteria

1. Feature-gated UI elements are hidden when the flag is disabled for the tenant. (FR-3.2, AC-3)
2. API endpoints for a disabled feature return a 403/404 for that tenant. (AC-3)
3. Tenant Admin can view the list of enabled/disabled features but cannot toggle any flag. (FR-3.4, AC-4)
4. A disabled feature shows a "request upgrade" prompt (optional). (FR-3.4)
5. Flag changes take effect on next request without restart. (FR-3.5, AC-2)
6. Tenant-side users (including Tenant Admin) cannot self-enable a disabled feature. (FR-3.4)
