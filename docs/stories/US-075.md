# US-075 - Mobile-First Ergonomic Touch UX & Flow Optimization

## Story

As a mobile user navigating the platform on a smartphone or tablet,
I want form actions to be easily reachable with my thumb, touch targets to be comfortably sized, and layouts to adapt seamlessly to mobile screens,
So that I can complete client and project workflows on the go with zero friction.

## Acceptance Criteria

- **AC-075.1:** Complex forms (`/app/clients/new`, `/app/invoices/new`, `/app/projects/new`, etc.) provide accessible sticky mobile action buttons at the bottom of the viewport with safe-area padding so users never lose context or scroll excessively to save.
- **AC-075.2:** All clickable buttons, tab items, dropdown triggers, and pagination controls adhere to the minimum 44×44px touch target guidelines on mobile viewports.
- **AC-075.3:** Virtual keyboards open with appropriate layouts (`inputmode="numeric"` for price/currency/tax numbers, `type="email"`, `enterkeyhint="next"`/`"done"`).
- **AC-075.4:** Tables on screens `< lg` display structured, high-contrast mobile cards with quick action shortcuts.
