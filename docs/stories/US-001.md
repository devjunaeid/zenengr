# US-001 — Frontend Docker image

## Story

As a developer, I want a Dockerfile for the SvelteKit frontend so I can run the app in the local Compose stack without manually installing Node/npm.

## Acceptance criteria

1. `frontend/Dockerfile` builds an image that runs `npm install` and produces the SvelteKit build.
2. Image runs on Node LTS (>= 20).
3. Build artifacts are produced via `npm run build`.
4. The container exposes the preview server port (default `4173`) or the dev port, configurable via the Compose service.
5. A `.dockerignore` excludes `node_modules`, `.svelte-kit`, and build outputs.
