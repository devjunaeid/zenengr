# US-024 — Template edits never mutate already-instantiated project milestones (FR-6.5)

## Story

As a staff member, I want to edit a service template without worrying about breaking existing project milestones so I can improve the template over time without disrupting active projects.

## Acceptance criteria

1. Editing a service template after one or more projects have used it does NOT change already-instantiated project milestones. (FR-6.5, AC-5)
2. New projects using the edited service get the updated template. (AC-6)
3. The system clearly warns when editing a template that has existing instantiations. (FR-6.5)
4. Project milestones are copies (instances) of the template at the time of project attachment. (FR-6.4)
