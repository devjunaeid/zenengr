# US-073 - Read-Only Company Analytics & Multi-Dimensional Ledger UI (/app/reports)

## User Story

As a **tenant administrator or manager**,
I want **a dedicated, read-only analytics page at `/app/reports` where I can filter company performance by date range, client, and project**,
so that **I can inspect company health, track growth across projects and services, review billing vs collections, and export reports for stakeholders in one place**.

## Acceptance Criteria

1. **Navigation:**
   - Adds "Reports" to the staff portal sidebar navigation with an analytics/chart icon, visible to users with `view/financial_reports` permission.
2. **Top Filter & Date Range Bar:**
   - Quick range presets: *This Month*, *Last Month*, *This Quarter*, *This Year (YTD)*, *Last 30 Days*, *Last 90 Days*, *All Time*, and *Custom Range*.
   - Client and Project searchable pickers allowing granular slicing.
   - Quick "Reset Filters" action.
3. **Executive KPI Cards:**
   - 7 cards with modern styling: New Projects, New Services, New Clients, Total Invoiced, Payments Collected, Outstanding Due, and Advance Credits.
   - Respects tenant numbering system and currency formatting via `<AmountInWords>` tooltip or subtitle where relevant.
4. **Three Tabbed Multi-Dimensional Views:**
   - **Timeline (Month / Date-wise):** Chronological table with visual progress/comparison bars for Invoiced vs Collected.
   - **Project-wise:** Data table with project status badges, service counts, totals, paid, and due amounts, with direct links to project details.
   - **Client-wise:** Data table with client names, active projects, invoiced, paid, dues, and advance balances, with direct links to client details.
5. **Search & Sorting:**
   - Real-time client-side search across tables.
   - Column sorting for financial values (highest due first, highest invoiced, etc.).
6. **CSV Export:**
   - One-click CSV export button downloading the active tab's dataset with properly formatted headers and values.
7. **Strictly Read-Only:**
   - No creation modals, write actions, or mutation buttons exist on this page.
