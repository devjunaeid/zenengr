# US-014 — Tenant Admin triggers password reset on behalf of a staff user

## Story

As a Tenant Admin, I want to trigger a password reset for another admin user so I can help them regain access without sharing credentials.

## Acceptance criteria

1. Tenant Admin can trigger a password reset for any active admin user in their tenant. (FR-4.12)
2. The affected user receives a password reset email. (FR-4.12)
3. This action is distinct from the user's own self-service forgot-password flow. (FR-4.12)
4. The action is recorded in the audit trail. (FR-4.13)
5. A deactivated user cannot receive an admin-triggered password reset. (FR-4.11)
