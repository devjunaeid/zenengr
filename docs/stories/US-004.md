# US-004 — Super Admin provisions a tenant (slug, plan, Trial status)

## Story

As a Super Admin, I want to create a tenant with a unique slug, assign an initial subscription plan, and set status to Trial so the new tenant's admin can start onboarding before converting to Active.

## Acceptance criteria

1. Super Admin can create a tenant with business name, unique slug, and initial status (default Trial). (FR-1.1, FR-1.2)
2. System validates slug uniqueness at creation time. (FR-1.2)
3. Slug is used for subdomain or login routing. (FR-1.2)
4. Tenant is created with status `Trial`. (FR-1.3)
5. Super Admin assigns a subscription Plan at creation time (default: Trial plan). (FR-2.1)
6. A Tenant Admin user is created alongside the tenant during provisioning. (FR-1.1)
7. Tenant isolation is enforced from moment of creation — no other tenant can see this tenant's data. (FR-1.4)
