# ADR-001 — Use token-based authentication

## Context

Need to authenticate users across frontend and backend API.

## Decision

Use JWT access tokens + refresh tokens stored in HTTP-only cookies.

## Consequences

- Stateless auth simplifies horizontal scaling.
- Requires careful token rotation and revocation handling.
- Refresh tokens must be stored securely.
